# Jugá con Cristian

Aplicación web de raspaditas para Panadería Cristian.

## Contenido

- `index.html`: juego web y estilos.
- `Code.gs`: backend de Google Apps Script para registrar participantes y reservar tarjetas.
- Imágenes `.jpeg`: logo, premios y diseño de las tarjetas.

## Publicación

La aplicación utiliza Google Sheets y Google Apps Script como backend. Antes de publicar cambios, actualizar la implementación web de Apps Script y verificar la URL configurada en `index.html`.
